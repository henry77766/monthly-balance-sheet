# 每月資產負債表

手機用的個人資產負債表，一個月填一次。

## 部署

1. 新增 repo，把 index.html、manifest.json、icon.svg 三個檔案放進去
2. repo 的 Settings 進 Pages
3. Source 選 Deploy from a branch，Branch 選 main、資料夾選 / root，按 Save
4. 等一兩分鐘，網址會是 https://你的帳號.github.io/repo名稱/

## 資料存在哪

存在瀏覽器的 localStorage，綁定網址和裝置。
清除瀏覽資料或換手機會不見，記得偶爾按「複製備份文字」留一份。

## 支出算法

上月現金 + 本月收入 - 轉去投資 - 本月現金
